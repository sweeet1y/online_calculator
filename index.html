Оптимизация использования воды в Казахстанеееее

Расчёт распределения воды между сельским хозяйством, промышленностью и коммунально-бытовым сектором.

Исходные данные

Секторaᵢ, тг/м³Dᵢ, млн м³

aᵢ — экономический эффект от 1 м³ воды, Dᵢ — минимальный объём воды для сектора.

Данные в примерах условные.

Оптимальное распределение

—
max Z — суммарный экономический эффект
—эффект при пропорциональном делении
—прирост за счёт оптимизации
—остаток (не распределено)
—эффект от +1 млн м³ воды
Секторxᵢ, млн м³ДоляЭффект, млн тг

Математическая модель

max Z = a₁x₁ + a₂x₂ + a₃x₃

Ограничения: x₁ + x₂ + x₃ ≤ W;  x₁ ≥ D₁, x₂ ≥ D₂, x₃ ≥ D₃

x₁ — объём воды для сельского хозяйства, x₂ — для промышленности, x₃ — для коммунально-бытового сектора; W — общий объём доступных водных ресурсов.

Порядок расчёта

  1. Проверка: D₁ + D₂ + D₃ ≤ W.
  2. Каждый сектор получает минимум Dᵢ.
  3. Остаток R = W − ΣDᵢ отдаётся сектору с наибольшим aᵢ.
  4. Результат сравнивается с пропорциональным распределением.

Решение

—
Объём — млн м³, aᵢ — тг/м³, Z — млн тг.
